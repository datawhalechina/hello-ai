# 35 素材管理：把散落的自媒体素材整理成素材库

[官网课程](https://www.datawhale.cn/learn/content/382/7932) · [飞书源稿](https://p0uxgq31evx.feishu.cn/docx/Kd1Ud79g6oARnFxa4yGc5gKUndg)

找一个你平时存素材的文件夹，借助能读电脑文件的AI工具，整理出一份方案：文件清单、新的文件夹结构、命名规则、每个文件改成什么名字放到哪里，还有需要再确认的文件，以及改错了怎么恢复。

做完以后，随便挑一个文件，你应该能说清楚它原来叫什么、建议改成什么、放在哪里、为什么这么放。

## 适合谁

平时素材多、经常要找旧素材的运营和自媒体作者。不需要会写代码。

---

## 开始前准备

### 准备素材文件夹

直接用自己的素材文件夹。第一次做建议挑几十个以内的。开始之前先复制一份，用副本来做，AI改动了文件，原版也还在。

如果手边没有合适的，可以用练习素材包。它从几篇公众号文章和活动海报里拷出来，文件名改得比较乱，基本就是平时存素材时常见的那种状态。

打开后里面有正文、图片、海报源文件、一个压缩包，还有一份来源清单。来源清单记着每篇内容的标题、渠道和使用范围，整理的时候拿来对照。练习素材包里标了两处注意事项：海报的源文件不能删，推理王国的两版稿子不能互相覆盖。

用自己的文件夹的话，也可以准备一份类似的清单，写上都有哪几篇内容、发在哪里、有没有不能删的文件。没有也没关系，第一步可以让AI根据文件内容帮你列一份。

### 让AI能读这个文件夹

用WorkBuddy或千问办公都可以：

1. 新建一个空文件夹叫"整理方案"，后面导出的东西都放这里
2. WorkBuddy新建任务把素材文件夹设为工作文件夹，或直接拖进对话框；千问办公新建对话把文件传上去
3. 先告诉AI这次不要改文件
4. 让它把能看到的文件列一遍，数量对上了再开始

先发这段话：

```text
这次只是请你帮我想一个整理方案，文件夹里的文件先都不要动，不要改名、移动、删除，压缩包也不要解压。结果直接发给我，或者存到"整理方案"文件夹。如果有哪一步必须改文件，先问我。
```

> 这次只是请你帮我想一个整理方案，文件夹里的文件先都不要动，不要改名、移动、删除，压缩包也不要解压。结果直接发给我，或者存到"整理方案"文件夹。如果有哪一步必须改文件，先问我。

然后确认：

> 请把你能看到的文件都列出来，写上文件名和类型，最后告诉我一共有几个。先不要做任何修改。

列出来的数量和文件夹对不上，一般是文件夹没选对或文件没传完，重新选一次再问。练习素材包里一共23个文件。

---

## 六个步骤

整理顺序：先让AI看一遍所有文件 → 分文件夹 → 起新名字 → 自己抽查几个 → 列出需要确认的 → 导出。

### 第一步：让AI打开每个文件看一遍

一开始不要让它直接分类、改名。文件名大多看不出内容，先让它打开看，弄清楚每个文件是什么。

**提示词：**

> 这个文件夹里是我平时存的公众号和活动素材，名字比较乱。你先不要改任何东西，帮我一个一个打开看看，列一个清单：每个文件里是什么内容，对应来源清单里的哪一条。压缩包看看里面有什么就行，不用解压。打不开的文件标出来，不用猜。

没有来源清单的话，把后半句换成"顺便帮我归纳一下，这些文件大概属于哪几篇内容"。

清单出来以后，先看数量对不对，再挑几个看看它的描述是不是真的打开过。比如练习素材包里有一张名字是一串数字的微信图片，如果AI只写了"一张微信图片"，可能是没有打开，可以提醒它重新看一下。

整理练习素材包的时候，这一步可以发现几件事：有两张截图其实是同一张图，压缩包里的东西外面基本都有，还有一张流程图在来源清单里找不到出处。AI不一定一次都能找出来，没关系，后面还有抽查。

如果清单很长，输出一半就停了，可以让AI分两次发。

### 第二步：分文件夹

有了清单，再考虑这些文件怎么放。一般分两层就够了：第一层按渠道，公众号的放一起，海报放一起；第二层按具体内容，文件夹名用来源清单里的编号开头。

另外多建几个文件夹放暂时处理不了的东西：以后的新素材、不确定的、重复的，还有压缩包。名字前面加个下划线，它们会排在最下面，不会和正常文件夹混在一起。

**提示词：**

> 按渠道和内容帮我分一下文件夹，最多两层，内容那一层用来源清单里的编号开头，比如"C02\_DeepAgents开源课"。另外建四个文件夹："\_收件箱"放以后的新素材，"\_待确认"放来源清单里找不到或者判断不了的，"\_待删除\_保留30天"放重复的文件，"\_原始压缩包"放压缩包，不解压。每个文件只放一个地方，先给我看一下怎么分的。

拿练习素材包来说，可以先看一下那两张海报，名字很像，其实是两次不同活动的，应该分在两个文件夹里。如果被放在了一起，说明AI还在看名字，提醒它打开看看。

### 第三步：起新名字，做一张对照表

文件夹分好以后再起新名字。格式是"内容编号\_内容主题\_素材类型\_序号"，比如 ` C02_DeepAgents开源课_配图01.png `。文件单独发给别人，看名字也知道是哪篇内容里的什么图。

起名字的时候提前说清楚这几种情况：同一篇文章存了两种格式的，名字里写清楚是哪一种；同一篇有新旧两稿的，用v1、v2区分，看不出哪个新的先标出来；改完如果有两个文件重名，先看是不是同一个，是的话留一个。

**提示词：**

> 帮我给每个文件起新名字，格式是"内容编号\_内容主题\_素材类型\_序号"，比如C02\_DeepAgents开源课\_配图01.png。"最终版""副本""(1)"这种词不要再用。同一篇有不同格式的，名字里写清楚是哪种；有新旧两稿的用v1、v2，看不出哪个新就先标出来问我。正文里用到的图叫"配图"，没用到的叫"备选图"。如果有两个文件会重名，先比较一下内容，一样的只留一个，多的放进"\_待删除\_保留30天"。
> 
> 
> 
> 最后做成一张表：原来的名字、新名字、放在哪、为什么这么判断、是否需要确认。先不要真的改名。

这一步最花时间。表出来以后，重点看名字里带"最终版"的文件。练习素材包里有一个带"最终版"的正文，其实是排版用的粘贴版，不是最新的；还有一张"最终版2"的规则图，是简版，不是第二版。这类文件只看名字很容易判断错，对照表再看一遍。

### 第四步：自己打开几个文件核对

AI做的表看起来很完整，但不一定都对。这一步只打开看，不改名，也不要拖动。

一般挑几张名字看不出内容的图片、一个来源清单里没有的文件、一对名字差不多的正文，再看一眼压缩包里有什么。

发现有问题的，告诉AI是哪几行，让它只改这几行：

> 这几行不对：【文件名，以及你看到的实际内容】。只改这几行，其他的不要动，改完告诉我改了什么。

没发现问题，就在表里备注一下你看了哪些文件，以后回头看也知道哪些核对过。

### 第五步：列出需要确认的文件，写好恢复说明

有些文件AI没法判断，比如正文里没用到的几张图还要不要，推理王国的两版稿子哪版是最后发出去的，那张来源不明的流程图能不能用。这些得问负责的同事。让AI把它们单独列出来，方便去问。

**提示词：**

> 把表里需要别人确认的文件单独列出来，写一下需要确认什么、应该问谁。不用给建议，列出来就行。
> 
> 
> 
> 再写一段恢复说明：如果以后按这张表真的去改，改之前要做什么，改的时候要记下什么，改错了怎么恢复。

恢复说明里至少要有这几条：改之前先复制整个文件夹备份；改的时候按表一行一行来，记下每个文件原来在哪、现在在哪；遇到重名就停下来，不要覆盖；改错了按记录改回去，找不到的从备份里拿。

如果AI在清单里写了"建议删除"这样的话，让它改成需要问谁。不确定的文件先放在原处，名字也不改。

### 第六步：导出方案

**提示词：**

> 把这次的整理方案存到"整理方案"文件夹，不要存到素材文件夹里。包括文件夹结构、对照表（Excel）、需要确认的文件、恢复说明，再加一段以后新素材怎么归档的做法。存好以后，帮我确认一下素材文件夹里的文件都没有变。

导出Excel不成功的话，直接把对话里的表格复制出来，存到自己的表格里。

## 怎样判断方案可用

| 检查什么 | 怎么看 | 怎样算可以 |
| --- | --- | --- |
| 有没有漏 | 对照表的行数和文件数对一下 | 每个文件都在表里，而且只放在一个地方 |
| 会不会重名 | 让AI检查新名字有没有重复 | 没有重复的名字 |
| 规则写清楚没有 | 看方案里有没有写分类方法和命名格式 | 别人照着规则，也能给新素材起名字 |
| 来源清单还在不在 | 看它放在哪 | 跟着素材一起保存 |
| 需要确认的列出来没有 | 看确认清单 | 每一个都写了问谁、确认什么 |
| 原文件动没动 | 打开素材文件夹看一下 | 文件还是原来的，名字没变，压缩包也没解压 |

最后一条最重要。如果原文件已经被改了，先用之前复制的那份恢复，再重新来一遍。

做完可以随便挑一个文件，看看自己能不能说清它的去向。比如那张微信图片，打开是Deep Agents的一张信息图，文章里没有用到，所以放到Deep Agents那篇的文件夹里，名字改成备选图，要不要留下再问一下负责的同事。每个文件都能这样说清楚，这份方案就可以用了。

## 下次直接复用

> 这次只是请你帮我想整理方案，文件都先不要动，不要改名、移动、删除，也不要解压压缩包。
> 
> 
> 
> 素材文件夹：【填写】
> 
> 
> 
> 有没有来源清单：【有就写在哪，没有就写没有】
> 
> 
> 
> 想怎么分文件夹：【比如先按渠道，再按内容】
> 
> 
> 
> 命名格式：【比如 内容编号\_内容主题\_素材类型\_序号】
> 
> 
> 
> 不能删的文件：【比如源文件、授权记录】
> 
> 
> 
> 请先打开每个文件，列一个清单，再给我文件夹的分法和一张对照表（原名、新名、放在哪、为什么）。不确定的先标出来问我。最后列出需要确认的文件，再写一段恢复说明。

## 遇到问题时

| 遇到的问题 | 可以这样处理 |
| --- | --- |
| AI说看不到文件，或者只看到一部分 | 一般是文件夹没选对，或者文件没传完。重新选一次，再让它列一遍 |
| AI自己改了文件名或者移动了文件 | 让它停下来，用之前复制的那份把文件夹恢复。再开一个新对话，先把"不要改文件"那段话发给它 |
| 压缩包被解压到了素材文件夹里 | 和上面一样处理 |
| 图片或SVG打不开 | 在清单里写上没打开和原因，不要让它猜 |
| 表格输出到一半停了 | 让它分两次输出，最后对一下总数 |
| 两个文件起了一样的名字 | 先看是不是同一个文件，是的话留一个，不是的话加个序号 |
| 导出Excel失败 | 把对话里的表格复制到自己的表格里 |

---

## 方案确认以后再改文件

建议先只做到出方案。方案确认过了，再去真的改文件。改之前把整个文件夹备份一份，最好先在备份上试一下。

让AI帮忙改也可以，但一次不要改太多，改完一批检查一下数量和名字，再改下一批。

以后有了新素材，先放进收件箱，每周找个时间按规则改名、放好。同一篇内容有了新稿，就用v2、v3，不要再叫"最终版"。要删的文件先放进待删除的文件夹，过一段时间确认没用了再删。源文件和授权记录不要删。
