# 文案改写：一份素材，写成三个平台的内容

[官网课程](https://www.datawhale.cn/learn/content/382/7927)

> 把同一份内容，改成公众号、知乎、小红书三个版本。不同平台有各自的风格特征，你只需提供观点和例子，AI 帮忙整理句子和各平台的适配风格，即可审核发布文案

## 三个平台风格和内容

| 平台 | 平台风格 | 你要写出的内容 |
| --- | --- | --- |
| **公众号** | 先讲一个常见困扰，再给出方法 | 1 个标题＋摘要＋短文 |
| **知乎** | 先回答“怎样保留个人表达？” | 1 个标题＋回答 |
| **小红书** | 先给结论，再列出三步做法 | 1 个标题＋正文＋封面字＋3 页图卡字 |

## 第一步｜准备母稿

**你要做什么:**
把你的核心观点和例子整理成一段清晰的文字(母稿)。

**核心观点****：**自己的判断说清楚很重要。

一篇文章不像自己，就是因为没有说清楚三件事：

- 写给谁看；
- 你真正想说的一个判断；
- 一个能说明判断的例子。

> **母稿示例**
> 
> 
> 
> 给 AI 一个主题，它可以很快写出一篇完整的文章，但读起来像谁都能发。比如写“第一次参加线下分享怎样做笔记”，我更建议不要记下所有金句，而是带走一个回去能尝试的动作，并写清楚第一步做什么。
> 
> 
> 
> AI 可以帮忙调顺序、换开头、删重复。观点、例子和最后的取舍，由作者自己确认。

## 第二步｜确定三个平台各自怎么写

| 公众号 | 知乎 | 小红书 |
| --- | --- | --- |
| 困扰 → 判断 → 例子 → 建议 | 问题 → 直接回答 → 做法 → 边界 | 结论 → 三步清单 → 读者行动 |

先写这一行结构，再写正文。我们可以根据不同平台的不同流量规则来做出不同的内容。

## 第三步｜动手改写

**你要做什么:**

1. 从母稿里找出不能改的观点和例子。
2. 分别写三个版本，每个平台准备 2 个标题，选 1 个留下。
3. 把 AI 生成的句子逐篇读一遍，删掉不像自己会说的话。

可以复制以下提示词，注意修改【】中的内容

> 三个平台的风格是
> 
> 
> 
> - **公众号:** 困扰 → 判断 → 例子 → 建议
> - **知乎:** 问题 → 直接回答 → 做法 → 边界
> - **小红书:** 结论 → 三步清单 → 读者行动
> 
> 
> 
> 不要改动的观点和例子是：【从母稿中找出你觉得不能改的观点和例子】
> 
> 
> 
> 把这份母稿分别改成公众号、知乎和小红书三个版本。保留我的观点和例子，不新增经历或效果。公众号写标题、摘要和短文；知乎第一段先回答问题；小红书写标题、正文、封面文字和 3 页图卡文字。先给出三个版本的结构，再写正文。

## 第四步｜自己用三个问题检查每一篇

| 检查 | 问自己 |
| --- | --- |
| 意思 | 这还是我原来想表达的观点吗？ |
| 事实 | 有没有把例子写成没发生过的经历？（自己的真实经历，IP感会更强） |
| 平台 | 这个平台的读者看完，收获了什么？ |

> **一个具体判断方法**
> 
> 
> 
> 原句：这场分享让我受益匪浅。
> 
> 
> 
> 如果说不出“哪里有用”，就删掉；如果确实准备试一个方法，就写出准备怎么试。

## 最后你会得到什么

把三个版本按“公众号／知乎／小红书”分开保存。这样，你手里就有一份可以继续排版的多平台内容包：每个平台都有选定的标题和完整正文，小红书还包括封面文字和 3 页图卡文字。发布前只需再核对事实、链接和配图。

## 三平台成品示例

### 公众号｜把事情讲完整

**标题：**让 AI 帮你写之前，先把自己的判断说清楚

AI 很快就能写出标题、开头和要点，但文章可能像谁都能发。写之前，先补上写给谁、自己怎么看、有什么例子。比如写做笔记，不必记下所有金句，可以选一个回去能尝试的方法，并写清第一步。材料说清楚后，再让 AI 调整顺序、删掉重复。最后由自己确认：这是不是我想说的话，例子是不是真的。

### 知乎｜先回答问题

**问题：**怎样用 AI 辅助写作，同时保留个人表达？

先把读者、判断和例子交给 AI，再让它整理表达。只给“写一篇做笔记的文章”这个主题，文章很容易空泛；补上“我更建议带走一个准备尝试的方法”，才有明确观点。AI 可以改顺序、换开头、删重复，但经历和取舍要自己核对。

### 小红书｜把方法拆开

**标题：**AI 初稿太空？先补这三样

**正文：**别只给 AI 一个主题。补上：写给谁、你怎么看、用什么例子说明。再让它改表达，自己检查有没有写进不存在的经历。拿一段旧稿试一次就好。

| 图卡 | 一句话 |
| --- | --- |
| 1 | 先说清写给谁 |
| 2 | 补上自己的判断 |
| 3 | AI 改表达，自己核对 |

> **做完后的检查**
> 
> 
> 
> 你应该能拿出三份稿件：公众号短文、知乎回答、小红书图文文字。它们讲的是同一个观点，但各自适合自己的平台。
